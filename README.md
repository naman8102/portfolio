# Naman Singh — Portfolio
React + Vite + TypeScript + Tailwind v4 + Framer Motion.
- `npm install && npm run dev` to run; `npm run build` for production.
- Edit all content in `src/data/portfolio.ts` (LinkedIn URL, photo, demo links).
- Add your resume at `public/resume.pdf` and a photo at `public/images/` (then set `photo` in config).
- Contact form: copy `.env.example` to `.env` and set `VITE_FORM_ENDPOINT`.
